# Experiment code and saved results

all four research questions, dependency setup, data preparation, training,
evaluation, and reproduction choices.

The **[final submitted report](../report.pdf)** is at the repository root.

Run the documented Python commands with this `Submission` folder as your
terminal's working directory. Existing completed results are in
[`results/full/`](results/full/). Use a separate `results/reproduction_*`
folder for new runs so the submitted evidence is preserved.
